# Presentation Slides

Written in **Marp** so they're git-friendly, diff-able, and can be
rendered to PowerPoint / PDF / HTML.

## Render

```powershell
# Install Marp CLI once
npm install -g @marp-team/marp-cli

# Render
marp docs\slides\deck.md -o docs\slides\deck.pdf
marp docs\slides\deck.md -o docs\slides\deck.pptx --pptx
marp docs\slides\deck.md -o docs\slides\deck.html
```

## Preview live

VS Code: install the **Marp for VS Code** extension and use the preview button.
